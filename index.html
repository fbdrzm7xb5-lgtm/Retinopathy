Reference scale

Five severity grades

Standard International Clinical Diabetic Retinopathy (ICDR) disease classification scale.

Grade 0 No diabetic retinopathy. Normal healthy fundus without vascular lesions.
Grade 1 Mild non-proliferative DR. Microaneurysms only.
Grade 2 Moderate non-proliferative DR. Dot/blot hemorrhages & hard lipid exudates.
Grade 3 Severe non-proliferative DR. Cotton-wool infarcts & 4-quadrant hemorrhages.
Grade 4 Proliferative DR. Neovascularization & vitreous/preretinal hemorrhage.
Project notes

Built for a transparent viva

Every claim belongs to the model, dataset, and evaluation evidence behind it.

Problem statement

Diabetic retinopathy can threaten vision. This project studies whether image-classification methods can support screening workflows, while keeping clinical decisions with qualified professionals.

Methodology

Image validation → architecture-specific preprocessing → verified DR classifier → probability distribution → clinical symptoms, precautions, and treatments.

Responsible by design

Confidence is not clinical certainty. Dataset bias, image quality, calibration, false negatives, and external validation all affect safe use.

Current project status

Full Spring Boot backend integrated. Supports Microsoft ONNX Runtime deep learning inference and client-side morphological classification fallback.

Medical disclaimer: This academic demonstration is not a medical device and does not provide diagnosis, treatment, or medical advice. Do not use this interface to make health decisions. Seek evaluation from a qualified eye-care professional.
