Before you begin

This interface is ready for a verified diabetic-retinopathy model endpoint. No model weights or backend are present in this starter workspace, so analysis is intentionally blocked rather than replaced with a made-up prediction.

  • Client-side type, size and readability checks
  • Preview before any analysis request
  • Five-grade labels shown only with a verified model
  • Images are not uploaded or persisted by this page

Project notes

Built for a transparent viva

Every claim belongs to the model, dataset, and evaluation evidence behind it.

Problem statement

Diabetic retinopathy can threaten vision. This project studies whether image-classification methods can support screening workflows, while keeping clinical decisions with qualified professionals.

Methodology

Image validation → architecture-specific preprocessing → verified DR classifier → probability distribution → educational explanation. Training and evaluation details must be supplied with the model.

Responsible by design

Confidence is not clinical certainty. Dataset bias, image quality, calibration, false negatives, and external validation all affect safe use.

Current project status

Frontend workflow implemented. Model, dataset, API, evaluation script, and Grad-CAM remain to be connected because none were present in the workspace.

Medical disclaimer: This academic demonstration is not a medical device and does not provide diagnosis, treatment, or medical advice. Do not use this interface to make health decisions. Seek evaluation from a qualified eye-care professional.
